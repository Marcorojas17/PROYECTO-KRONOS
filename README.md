# CRONOS — Sistema de Interpretación Temporal y Simbólica

> **Cognitive Relational Ontology for Networked Observations and Systems**

Sitio estático del Proyecto Cronos. Arquitectura filosófica y tecnológica que estudia
cómo los seres humanos convierten símbolos en decisiones, cómo los algoritmos detectan
patrones y cómo la información cambia con el tiempo.

## Qué es este repositorio

Un sitio **estático** publicado con **GitHub Pages**. Sin build, sin terminal,
sin Docker. Solo HTML, CSS y JavaScript puro.

## Publicación en GitHub Pages

1. Sube `index.html`, `styles.css`, `app.js` y `.nojekyll` a la raíz del repositorio.
2. Ve a **Settings → Pages**.
3. En **Source**, elige `Deploy from a branch`.
4. Selecciona la rama `main` y la carpeta `/ (root)`.
5. Guarda. El sitio estará disponible en
   `https://<usuario>.github.io/<repositorio>/`.

## Principios

- No predice el futuro.
- No sustituye decisiones médicas, legales o financieras.
- No confunde simulación matemática con computación cuántica real.
- No mezcla ficción con ciencia.
